# Changelog

## 1.0.0 - 2026-11-09

First release.

- Nine core skills: workspace-hygiene, safe-computer-use, file-finder, office-documents, data-analysis, browser-research, system-diagnostics, desktop-control, coding-agent-handoff.
- Eight role profiles: personal assistant, lecturer, PhD researcher, HR officer, IT support, student, communications, administrative assistant.
- Tools (standard library only): `scratch.py` task scratch folder with cleanup ledger, `find_files.py` read-only finder, `office_inspect.py` dependency-free Office inspector, `sysinfo.py` read-only system snapshot.
- `AGENTS.md` template, Windows and POSIX installers with backup and uninstall, `validate_skills.py` checks matching Open Terminal's skill loader, pytest suite.
- `ARCHITECTURE.md` describing Tether 0.1.12 and Open Terminal 0.17 (relay, IPC, runtime bootstrap, sandbox, skill discovery).
