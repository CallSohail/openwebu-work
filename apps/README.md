# Apps

Channel apps are external services that join Open WebUI channels as members. They are not pasted into Open WebUI: each one is a program you run, and Open WebUI connects to it. See the [Apps](https://docs.openwebui.com/features/channels/apps) and [Building Apps](https://docs.openwebui.com/features/channels/building-apps) documentation.

| App | Version | Purpose |
| --- | --- | --- |
| [Pulse](pulse/) | 0.1.1 | Polls with live vote buttons, and a tour of what apps can do |
| [Longshot](longshot/) | 1.0.0 | Long bets: a claim, a deadline, two sides, a notice when time is up, and a scoreboard |
